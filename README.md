# DEPO PROVERA

The source for the DEPO PROVERA case acquisition firm website. This site provides educational information about Depo-Provera claims and connects potential clients with attorneys in the firm's network.

## Run locally

Install dependencies with pnpm, then run `pnpm install` and `pnpm --filter @workspace/depo-provera-lawsuit run dev`.

The contact form is informational and does not create an attorney-client relationship.
